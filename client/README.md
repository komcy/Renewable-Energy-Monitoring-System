# REMS client

React 19 + Vite + Tailwind CSS 4 front end for the Renewable Energy Monitoring System.
See the [main README](../README.md) for setup, scripts and architecture.

```bash
npm run dev      # http://localhost:5173 (expects the API on :5000)
npm run lint
npm run build    # outputs dist/, served by the API in production
```
